Aprende vistas en SQLite

¿Qué es una vista?

Una vista es una consulta SELECT guardada en la base de datos y presentada como si fuera una tabla. No guarda una copia de las filas: al consultar la vista, SQLite ejecuta su consulta sobre las tablas originales.

En esta lección usaremos crime_scene_report de la base del misterio para guardar y reutilizar el informe del crimen ocurrido en SQL City el 15 de enero de 2018.

Antes de empezar: los cambios de estos ejercicios viven en la copia de la base que carga la página. El botón «Restablecer» solo limpia el editor; vuelve a cargar la página para empezar de nuevo con la base original.

1. Crear una vista

Usa CREATE VIEW nombre AS SELECT ... para guardar una consulta. La vista de este ejemplo reúne el tipo, la fecha, la ciudad y la descripción del informe inicial.

Si la vista ya existe, otro CREATE VIEW con el mismo nombre devuelve un error. En SQLite puedes usar CREATE VIEW IF NOT EXISTS para evitar ese error, pero eso no cambia una vista que ya estaba creada.

2. Consultar y filtrar una vista

Una vez creada, puedes usarla en FROM como usarías una tabla. También puedes seleccionar algunas columnas y añadir filtros a la consulta.

3. Reemplazar una vista

SQLite no admite CREATE OR REPLACE VIEW. Para cambiar la consulta guardada, elimina la vista y créala otra vez con la nueva definición. En una aplicación real, considera los objetos que dependen de esa vista antes de eliminarla.

4. Eliminar una vista

Cuando ya no necesites una vista, usa DROP VIEW. La tabla original y sus datos no se eliminan. La consulta siguiente comprueba en el catálogo de SQLite que la vista ya no existe.

¿Qué límites tienen las vistas?

  • Una vista guarda una consulta, no los resultados ni una copia de los datos.
  • Si cambian las filas de las tablas originales, las consultas a la vista reflejan esos cambios.
  • En SQLite, una vista no se puede modificar directamente con INSERT, UPDATE o DELETE si no se ha definido un disparador INSTEAD OF para esa operación.
  • La vista solo expone las columnas que selecciona su definición.

Las vistas ayudan a reutilizar consultas, ocultar columnas que no hacen falta y simplificar consultas frecuentes, pero no sustituyen el diseño de las tablas ni aceleran por sí solas una consulta.

Práctica

Prueba por tu cuenta lo aprendido. Primero crea una vista con el primer editor; después consúltala en el segundo.

Al terminar, recarga la página para eliminar las vistas de práctica y volver a cargar la base original.
