El misterio del asesinato SQL

¿Puedes descubrir quién fue?

¡Ha ocurrido un asesinato en Ciudad SQL! El misterio del asesinato SQL está diseñado tanto como una lección autodidacta para aprender conceptos y comandos de SQL como un juego entretenido para que usuarios con experiencia resuelvan un intrigante crimen.

¿No conoces SQL?

Este ejercicio está pensado más como una forma de practicar tus habilidades con SQL que como un tutorial completo. Si nunca has usado SQL, prueba la guía paso a paso. Si de verdad quieres aprender mucho sobre SQL, quizá prefieras un tutorial completo como Select Star SQL.

Si ya te sientes cómodo con SQL, ¡puedes empezar aquí!

Si ya tienes experiencia con SQL, empieza aquí

Se ha cometido un crimen y el detective necesita tu ayuda. Te entregó el informe de la escena del crimen, pero de algún modo lo perdiste. Recuerdas vagamente que fue un ​asesinato​ ocurrido en algún momento del ​15 de enero de 2018​ en ​SQL City​. Empieza por recuperar el informe correspondiente de la base de datos del departamento de policía.

Explorar la estructura de la base de datos

Quienes tienen experiencia con SQL suelen poder inferir la estructura de una base de datos mediante consultas. Sin embargo, cada sistema de bases de datos administra esta información de manera distinta. El misterio del asesinato SQL usa SQLite. Ejecuta este comando SQL para encontrar las tablas de la base de datos del misterio.

Además de conocer los nombres de las tablas, necesitas saber cómo está estructurada cada una. El procedimiento también depende de la tecnología de base de datos que uses. Así se hace en SQLite.
